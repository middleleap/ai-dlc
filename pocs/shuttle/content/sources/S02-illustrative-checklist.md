# Illustrative workflow checklist — demo-v1

This checklist supplies synthetic discussion items, not regulatory obligations or a bank-approved control path. No statutory citations or compliance conclusions are asserted.

| Demo item | Discussion evidence to obtain later |
|---|---|
| Case scope | Confirm service, role, data/actions and exclusions with the case owner. |
| Consent journey | Identify the relevant consent journey and its owner; validate applicability separately. |
| Data boundary | Confirm permitted input/output data, retention and sharing rules. |
| Access | Confirm the application's actual user and file access model. |
| Operations | Name an operations owner and the support/exception process. |
| Document set | Identify which real templates may be used and shared. |
| Authority | Name the real decision makers and independent review rules. |
| Platform fit | Confirm services, licensing, region, providers and preview acceptance. |

A linked file is not proof that these items are satisfied. A typed owner name is not an authenticated decision. The demo operator must keep unmet items visible.
