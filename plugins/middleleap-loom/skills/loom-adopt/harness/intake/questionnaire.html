Prepare your first team

  1. Gather the institution's approved sources with /middleleap-loom:institution-intake. Use brainkit-init to draft missing context for review.
  2. Open the team's repository in Claude Code and run /middleleap-loom:loom-adopt. Review prerequisites and the proposed installation before applying it.
  3. Run node scripts/loom.mjs configure for setup tasks and owners, then node scripts/loom.mjs gates for repository checks.

Installation and passing checks do not establish institutional approval or platform activation. Follow the adoption guide for the applicable evidence and human decisions.

Before the first problem

Tell the Loom how your institution works, and where that is written.

Nine blocks, one per accountable role. Answer only your block. Every question asks two things: what is true here, and which document says so. That second field decides what happens to your answer.

  • Reference supplied (SOURCED in JSON): you named a document, register or signed decision. A reference is supplied; the source still needs retrieval and accountable review before use.
  • Claimed: you answered from experience. It goes to the gap register with your role as owner, to be written down.
  • Unknown: left blank. It goes to the gap register for escalation.
  • Roles, never names. Nothing you type here is approved by typing it. Save status is shown below. Export a backup before leaving or switching devices; browser storage is not shared.

Export

Hand the record to the facilitator

Download the record and send it through your approved institutional channel. The facilitator reviews imports before combining answers. The record is a JSON file, intake-record.json, saved to institution/intake/ in the repository. The institution-intake skill imports it and interviews only the gaps; brainkit-init drafts from the sourced answers. It carries authority: none on purpose.
